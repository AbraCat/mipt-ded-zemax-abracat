# MIPT-ded-zemax

Оптический конструктор с использованием алгоритма рей трейсинга и поддержкой плагинов.

## Компиляция и запуск

CMakeLists.txt файл проекта предполагает наличие исходного кода библиотек SDL3 и SDL3_ttf, склонированного с официальных репозиториев, в директориях sdl/ и sdl-ttf/ соответственно. Если вы линкуете эти библиотеки другим спосообом, измените файл CMakeLists.txt соответствующим образом. Также предплагается наличие ttf файла со шрифтом по пути ttf/font.ttf.

```
cmake --build build && ./build/main
```
